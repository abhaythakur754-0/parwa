# PARWA Help Center - Knowledge Base

## Getting Started with PARWA

PARWA is an AI-powered customer support platform that helps businesses automate their customer service. Our platform uses advanced AI models to understand customer queries and provide accurate, helpful responses.

### Account Setup
1. Sign up at parwa.buzz with your business email
2. Choose your variant: Starter, Growth, or High
3. Upload your knowledge base documents
4. Configure your support channels (email, chat, SMS)
5. Start receiving AI-powered responses

## Common Issues

### Reset Password
1. Go to parwa.buzz/login
2. Click "Forgot Password"
3. Enter your email address
4. Check your inbox for the reset link
5. Click the link and set a new password

### API Key Issues
If your API key is not working:
1. Check that the key hasn't expired
2. Verify you're using the correct environment (live vs test)
3. Regenerate the key from Settings > API Keys
4. Ensure the key has the required permissions

### Ticket Not Getting AI Response
If a ticket stays in "Open" status without an AI response:
1. Check that your variant is active (not expired)
2. Verify your knowledge base has been indexed
3. Check the AI Engine status in Dashboard
4. Ensure your API keys are configured correctly
5. Contact support if the issue persists

### Channel Configuration
To set up your support channels:
1. Go to Settings > Channels
2. Select the channel type (Email, Chat, SMS)
3. Follow the setup wizard for each channel
4. Test the connection
5. Enable the channel

## Security & Compliance

### Data Protection
- All data is encrypted at rest and in transit
- We comply with GDPR and SOC 2 Type II
- Regular security audits are performed
- Data is stored in region-specific data centers

### Two-Factor Authentication
Enable 2FA for your account:
1. Go to Settings > Security
2. Click "Enable 2FA"
3. Scan the QR code with your authenticator app
4. Enter the verification code
5. Save your backup codes in a secure location
